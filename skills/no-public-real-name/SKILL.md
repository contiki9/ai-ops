# 外部向け文章に実名を書かない

どのリポジトリでも守る。このリポジトリだけの例外ではない。

## 制約

- 利用者（GitHub: `contiki9`）の実名を、外部に出る場所に書かない。
- 対象は姓・名、漢字・ローマ字、敬称付きの呼び方を含む。
- 対象の場所は PR のタイトルと本文、Issue、コメント、コミットメッセージ、リポジトリ内の追跡ファイル。
- 人を指すときは `contiki9`、または「運営者」「リポジトリ所有者」を使う。
- グローバルの Git 設定と Cursor の自動コミット者名は対象外。
- 実名の文字列そのものを、この技能・AGENTS.md・PR に列挙しない。

## Cursor の User Rules

常時効かせるには、Cursor の Customize → Rules（User Rules）にも同じ制約を置く。
User Rules は全プロジェクトと Cloud Agent に載る。
この技能だけだと、呼び出されない会話では抜け得る。
